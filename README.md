#  Dino Catalog API

REST API для каталога динозавров. Позволяет управлять геологическими периодами, типами питания и динозаврами.

---

##  Описание проекта

API разработан на **Django REST Framework** с использованием базы данных **Microsoft SQL Server**.

### Сущности:

| Модель | Описание |
|--------|----------|
| **Period** | Геологический период (Триас, Юра, Мел) |
| **Diet** | Тип питания (Хищник, Травоядный, Всеядный) |
| **Dinosaur** | Динозавр (название, длина, вес, период, тип питания, описание) |

---

##  Использованные библиотеки

Все зависимости перечислены в файле `requirements.txt`.

Основные:
- **Django 4.2.20** — веб-фреймворк
- **djangorestframework 3.15.2** — создание REST API
- **mssql-django** — драйвер для Microsoft SQL Server
- **drf-spectacular** — документация Swagger/OpenAPI
